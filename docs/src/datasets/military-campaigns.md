# Military Campaigns

[data.everef.net/military-campaigns/](https://data.everef.net/military-campaigns/) contains archived snapshots of military campaigns from the ESI API.

Each snapshot includes the full list of campaigns from `/military-campaigns`, enriched with per-campaign objectives fetched from `/military-campaigns/{id}/objectives`.

Archives are stored as bzip2-compressed JSON (`.json.bz2`). A plain JSON latest file is also kept at the root of the directory.
